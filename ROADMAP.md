# Cali PWA Agency — Master Roadmap & Versioning Policy

**Current Version:** `v0.9.0` (Complete — Parts A, B & C Shipped)  
**Target Platform:** Standalone Android APK (Capacitor + React + TS + Vite + Tailwind + Three.js) & Web/iOS PWA (Vercel)  

## Versioning Policy (`vx.y.z`)
- **`x` (Major):** Bumped **only** upon explicit confirmation from Mark (e.g., `v1.0.0`).
- **`y` (Minor):** Increments per completed roadmap phase.
- **`z` (Patch):** Bug fixes & targeted upgrades within a phase.

## Completed Phases
- **`v0.1.0` – `v0.7.0`** — Scaffold, Monolith UI, 16-Bit & Claw3D 3D Office, Mandatory Onboarding, Snapshot Diff, Live Voice Tools, Local Directory Chooser, Offline-First Supabase Auth & 3-Layer JARVIS Brain.
- **`v0.8.0` – `v0.8.2`** — Login -> Project Hub -> Scoped Dashboard, IndexedDB + Live Local Folder Sync, Atomic Phase 1->2 Advance, Grey-Out Chat CTAs, Editorial Reports Hub, 24-Person 4-Tier Company, 4-Gate Voice Planning, Suggestion Board, 1-on-1 Coaching Pods, 8-Room Office, and Among Us-Style Blast Alerts.
- **`v0.9.0` (Current):**
  - **Local-First AES-256-GCM Encrypted Vault (`PBKDF2`):** Encrypts all 5 API keys, model selections, GitHub PAT, Cali Brain, and Agent Brains into `Documents/<folder>/cali-vault.enc.json`.
  - **Code Quality Overhaul:** Full `blueprint_md` injection into every worker, **Anti-Stub Pre-Check Gate**, **Per-Role Model Routing**, and 24 deep domain-specific core prompts.
  - **Individual Agent Brains & Off-Hours Web Study:** Persistent XP/Level/Lessons/Study Notes per agent + Gemini Google Search Grounding with daily quota caps.
  - **28 Consolidated On-Demand Visiting Contractors:** Merged from ~282 overlapping roles across 8 specialized divisions with distinct non-generic prompts, Marketplace UI, Cali auto-summoning, and Termux `compile-specialists.mjs` importer.

## Reserved Milestone
- **`v1.0.0`** — Production Release (held until on-device testing is complete and Mark explicitly confirms the major version bump).
