# Cali PWA Agency — Master Roadmap & Versioning Policy

**Current Version:** `v0.8.0` (Complete — Parts A, B & C Shipped)  
**Target Platform:** Standalone Android APK (Capacitor + React + TS + Vite + Tailwind + Three.js) & Web/iOS PWA (Vercel)  

## Versioning Policy (`vx.y.z`)
- **`x` (Major):** Bumped **only** upon explicit confirmation from Mark (e.g., `v1.0.0`).
- **`y` (Minor):** Increments per completed roadmap phase.
- **`z` (Patch):** Bug fixes & targeted upgrades within a phase.
