# Cali PWA Agency — Master Roadmap & Versioning Policy

**Current Version:** `v0.4.0`  
**Target Platform:** Standalone Android APK (Capacitor + React + TS + Vite + Tailwind) & Web Preview (Vercel)  

## Versioning Policy (`vx.y.z`)
- **`x` (Major):** Bumped **only** upon explicit confirmation (e.g., `v1.0.0`).
- **`y` (Minor):** Increments per completed roadmap phase.
- **`z` (Patch):** Bug fixes & micro-patches.

## Completed Phases
- **`v0.1.0`** — Scaffold & Debug APK CI.
- **`v0.2.0`** — Cali Monolith HQ & 16-Bit Pixel Office.
- **`v0.3.0`** — Mobile UX Overhaul, `AQ.` Keys + Model Auto-Detect, & Autonomous Loop Engine.
- **`v0.4.0` (Current)** — Mandatory Conversational Onboarding Gate (accurate `0/4` progress), 100% Custom-Coded Model Picker (zero native OS popups), Always-Visible Enlarged Floating Bottom Dock with Centered Home (no close buttons on primary views), Native Local Save (`@capacitor/filesystem` + web fallback), Full Local State Backup/Restore, Chat-to-Blueprint Live Card, Built-In SVG App Icon & Manifest Generator, and Per-Agent Latency & Token Inspector.

## Upcoming Phases
- **`v0.5.0`** — Release Candidate Hardening (Snapshot Diff Viewer, full Gemini Live voice tool-calling, multi-phase stress testing).
- **`v1.0.0`** — Production Milestone (reserved until explicit confirmation).
